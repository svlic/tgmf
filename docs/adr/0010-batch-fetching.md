## 原因与分析

- **U**：50 是经验值，不是基准测试最优值。
- **B**：减少远程往返和数据库写入；已经缓存相册成员时，再缓存廉价派生选择结果未必值得。
- **C**：未取得吞吐、RPC 减少比例或内存峰值，不报告量化优化成功。

## 代价和重审条件

进度显示允许短时落后；窗口为 50 不代表总缓存只有 50：当前消息和相册 Map 在任务结束前没有淘汰，范围 ID 也完整生成。
先依据真实大任务规模验证内存，再考虑滑动窗口／生成器，不为了经验参数立即引入复杂缓存系统。见 TD-11。
